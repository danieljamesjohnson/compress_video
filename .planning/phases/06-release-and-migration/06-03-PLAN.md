## Decisions implemented here

The numbering comes from the table in `06-01-PLAN.md` → "Decisions implemented here".
- **D-05**: generator plus CI drift gate.
- **D-06**: the non-goals section.
- **D-12** (discretion, chosen here): table layout. There is one row per `CompressPreset`, and the columns are
  `Preset` | `Longest side (px)` | `Video bitrate target` | `Frame rate cap` |
  `From a 1080p60 phone clip: Android` | `… iOS` | `… macOS`.
  - Each "From a clip" cell reads like `720×1280, 1.48 Mbps`. It is taken from that platform's
    `portrait_hibitrate_1080p60` row, using the Width×Height and Video bitrate (bps) columns
    formatted to 2 decimal Mbps.
  - The bitrate target is formatted like `2.5 Mbps (at 30 fps)`, and the frame rate cap like `30 fps (never raised)`.
  - Under the table, three generated plain-English sentences cover three points:
    - The target bitrate scales down with resolution and frame rate, and nothing is ever upscaled.
    - Android numbers are from the emulator's software encoder, and a phone's hardware encoder will differ.
    - Full measurements are in doc/PRESETS.md.

  The README already uses the heading "What this plugin deliberately does not do", which matches
  RELS-02's own wording, so that heading is kept rather than renamed to CONTEXT.md's paraphrase.

**Why the generator runs under `flutter test`.** `package:compress_video/compress_video.dart`
imports `package:flutter/foundation.dart` and `package:flutter/services.dart`, which need
`dart:ui`, so a plain `dart run` cannot load it. The generator therefore declares its work
inside a `flutter_test` `test(...)` and is invoked as `flutter test tool/generate_preset_table.dart`,
the same approach `tool/measure_presets.dart` already takes. Task 1 confirms `dart run` fails first
and records the error line in the SUMMARY. If `flutter test` will not accept a path outside
`test/` without a `_test.dart` suffix, the file is named `tool/generate_preset_table_test.dart`
instead, and every reference in this plan follows that name. That is a pure rename; the SUMMARY
records it.
