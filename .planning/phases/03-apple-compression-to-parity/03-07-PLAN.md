<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller-supplied trim range → reader | Start and end milliseconds are attacker-influenced integers used to construct a time range and to size a predicted output |
| caller-supplied output path → filesystem | An explicit destination decides where the plugin writes, inside the host app's sandbox |
| plugin cache directory → clearCache | A bulk delete is the single most destructive operation this package performs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-29 | Tampering | A trim range that is inverted, zero-length or beyond the source producing an unbounded read or an empty file | medium | mitigate | The Dart validators reject the invalid combinations before the channel and the native argument check mirrors them; the sidecar derivation additionally refuses a range that is not strictly inside the fixture's own measured duration |
| T-03-30 | Tampering | An explicit output path escaping the intended directory via `..` or a symlink | high | mitigate | The existing `Arguments.swift` writable-output-parent check resolves symlinks and requires an existing parent, and is reused rather than forked; the missing-parent case asserts the typed failure and that nothing is left behind |
| T-03-31 | Tampering | `clearCache()` deleting a file the plugin did not write | high | mitigate | The sweep is bounded to the plugin's own cache subdirectory, resolves every candidate's symlinks, never recurses, and excludes live jobs' temp paths; the control-file and sibling-subdirectory assertions prove it on both Apple platforms, alongside 03-02's on-disk symlink escape unit case |
| T-03-32 | Denial of Service | `estimate()` quietly doing the encode's work and blocking the caller | medium | mitigate | `estimate` constructs no reader, writer or export session, and the existing case asserting it completes far faster than the encode it predicts runs on both Apple platforms |
| T-03-33 | Repudiation | A published preset table that nobody can reproduce, so a later regression cannot be distinguished from a documentation error | medium | mitigate | Every Apple number comes from `tool/measure_presets.dart`'s own machine-readable output, the raw lines are recorded in the summary, and the section states the device, date and reproduction command |
| T-03-SC | Tampering | Third-party package supply chain | low | accept | This plan adds no package from any registry |
</threat_model>
