<objective>
Make the Apple half of JOBS-05 honest: give every iOS job the extra execution time the system
offers, and when that time runs out or AVFoundation reports the interruption, resolve the job as a
retryable `interrupted` failure with its partial file deleted — never a hang, never a `null`.

Purpose: iOS cannot be made to keep encoding indefinitely in the background, and pretending
otherwise is what the incumbent did. The deliverable is not survival; it is an accurate, typed,
retryable answer, symmetrical with the Android reason 05-03 made real, and documentation a caller
can build a retry on.
Output: an iOS-only background-task wrap, the interruption mapping, byte-identical XCTest coverage
on both Apple platforms, and the README section that tells callers what to do about it.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iOS system → the plugin | The expiration handler is an inbound, time-boxed system callback the plugin cannot decline or extend |
| AVFoundation error values → the reason taxonomy | A numeric code and a domain string decide which typed reason a caller receives and therefore whether they retry |
| running job → partial output on disk | An interrupted export leaves a partially written file whose contents came from the user's video |
| plugin → host app capabilities | Anything the plugin declares in its podspec, `Package.swift` or the host `Info.plist` is imposed on every consuming app |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-18 | Denial of Service | A job hanging forever when the system suspends the app, with its future never resolving | high | mitigate | The expiration handler cancels the job through the existing cancellation path, which resolves the suspended call with a typed error; `CompressJob._run`'s last-resort wrap guarantees the future resolves even for an unexpected failure shape, and the Dart round-trip case proves the caller sees a typed exception |
| T-05-19 | Information Disclosure | A partially written video file left on disk after an interruption | high | mitigate | The interruption reuses the engine's existing cancellation cleanup, which deletes the temp file before resolving; the plan explicitly forbids inventing a second cleanup path that could diverge |
