## Decisions Made
- Used a `mandelbrot` lavfi source at 60fps with a CBR-like 8Mbps target (`-b:v -maxrate -bufsize` all equal at 8M) for the high-bitrate clip, because high-entropy fractal content forces the encoder near its full budget on every frame; the resulting measured bitrate (8,764,164 bps) cleared the 6,000,000 bps floor on the first run with no retuning needed.
- Kept the edge-probe inset (4px) well inside the border width (24px) so the sample point lands inside the border regardless of which axis the 90° rotation swaps.
- `assert_size()` took an optional second argument (`max_bytes`, defaulting to the pre-existing `DEFAULT_MAX_BYTES` global) rather than a mandatory per-call rewrite, so the change is additive; the three Phase 1 call sites were still updated to pass the constant explicitly for readability, with no behavior change (confirmed via `git diff --exit-code` on all three Phase 1 clips and their sidecars).
