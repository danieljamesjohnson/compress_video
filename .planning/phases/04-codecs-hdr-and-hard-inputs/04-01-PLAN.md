## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ffmpeg-authored fixture → native decoder | Every new clip is untrusted input to `MediaExtractor`/`MediaCodec` and `AVAssetReader`; the HDR clips carry metadata (mastering display, max-CLL, 10-bit transfer) no previous fixture exercised |

| CI log text → parity gate | The gate's entire input is text scraped out of runner logs; a split step that writes over another step's log would silently shrink that input |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
