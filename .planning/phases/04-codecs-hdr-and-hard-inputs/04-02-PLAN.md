<objective>
Make Android do the right thing with the two input classes every competitor got wrong: HDR video
that must come back as SDR without looking washed out, and audio that is not plain stereo AAC.

Purpose: CDEC-02 and AUDO-03 are both "the plugin must not fail, and must not lie about what it
did". The mechanism for the first is `Composition.HdrMode` plus honest reporting from
`ExportResult.colorInfo`; the mechanism for the second is a forced re-encode trigger that the
current code genuinely does not have — 04-RESEARCH.md found that a 5.1 AAC source under default
options would sail straight through the passthrough branch with six channels intact, and would
very likely take the transmux fast path while doing it.
Output: an Android engine that tone-maps, reports it, downmixes what it must, and an integration
suite that proves each of those on real files rather than by inspection.
</objective>

## Decision map

IDs assigned in 04-01-PLAN.md's decision map; the rows this plan implements:

| ID | 04-CONTEXT.md decision |
|----|------------------------|
| D-02 | "Not washed out" is asserted by sampling the produced file; the test asserts the sampled saturation/luma land within a documented tolerance and that the result reports `toneMapped: true`. |
| D-03 | Android: request `HDR_MODE_TONE_MAP_HDR_TO_SDR_USING_OPEN_GL` first, fall back to `HDR_MODE_TONE_MAP_HDR_TO_SDR_USING_MEDIACODEC` (API 31+); if neither path is available, fail with a typed `unsupportedInput` error rather than emit washed-out video. Never silently pass HDR through when SDR was requested. |
| D-09 | 5.1 audio is downmixed to stereo AAC at 128 kbps (Media3 `ChannelMixingAudioProcessor`), reported `audioReencoded: true`. |
| D-10 | PCM audio is re-encoded to stereo AAC at 128 kbps, reported `audioReencoded: true`. |
| D-11 | No-audio sources continue to produce no audio track. |
| D-12 | The 4K60 corpus clip compresses on the emulator and the simulator inside the per-test timeout. |
| D-13 | All of these cases live in the one `hard_inputs_test.dart` suite. |
